Дълго време си записвах нещата по тетрадки, в бележки на телефона и в README файлове, които никой не чете. Този сайт ги събира на едно място: кратки бележки, проекти, формули, маршрути и снимки.

## Какво ще има тук

- **Блог** – всяка публикация е обикновен Markdown файл в хранилището.
- **Проекти** – списъкът идва от база данни в Neon, а ако няма връзка – от JSON файл.
- **Карти и формули** – само там, където текстът има нужда от тях.
- **Галерия** – снимки от разходки.

![Езеро под върховете в мъгливо утро](./images/mountain-lake.jpg)

## Как се публикува

Всяка промяна в клона `main` пуска GitHub Actions, който генерира статичния сайт и го качва в GitHub Pages. Целият цикъл е един ред:

```bash
git add . && git commit -m "Нова публикация" && git push
```

А ето малката функция, която смята времето за четене най-горе на страницата:

```js
export function readingTime(text, wordsPerMinute = 200) {
  const words = text.trim().split(/\s+/).length;
  return Math.max(1, Math.round(words / wordsPerMinute));
}
```

> Добрата бележка е тази, която след година ще разбереш без контекст.

| Част | Къде живее |
| --- | --- |
| Публикации | `src/content/blog/*.md` и `*.mdx` |
| Проекти | Neon или `src/data/projects.json` |
| Снимки | `src/assets/gallery/` |
